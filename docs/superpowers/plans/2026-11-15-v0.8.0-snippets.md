## Requirements
- A snippet is a named, saved command or shell script you can paste or run on hosts without retyping. Fields: Name, Script (multi-line), optional Package (folder). Snippets sync (model `Snippet` exists: id, name, script, package: String?).
- **Snippets screen** (sidebar "Snippets", today a placeholder): list grouped by package, search (name + script), New Snippet, edit (saves automatically), New snippet package, move snippets into a package (editor picker; drag several onto a package), right-click Remove (+ Duplicate, Run…).
- **Terminal side panel** (⌘. in a terminal tab, also from the tab's right-click menu "Snippets…"): list + search + New Snippet; hover a snippet → **Paste** (insert without running) / **Run** (insert + Return); double-click runs. Right-click → **Run in all tabs** (every open tab of this window, after a confirmation naming how many), Edit, Remove.
- **Run on several hosts** (from the Snippets screen): open a snippet → pick target hosts → Run: opens a new connection per host and runs the snippet after each is ready (password prompts as usual). "Save targets" remembers the hosts.
- **Startup snippet per host:** Host Details "Startup snippet" picker (model field `Host.startupSnippetID` exists and already runs after `.ready`); **Ruling:** host only this round (groups later); snippets with placeholders can't be startup snippets (hidden from the picker, with a note).
- **Placeholders:** `{{name}}` or `{{name:default}}` in a script; before Paste/Run (any route) a small form asks for each distinct name (prefilled with defaults, first field focused, Return = Run/Paste, Esc cancels). Names: letters, digits, `_`, `-`, spaces trimmed. `{{` without a valid closing is literal. Values are inserted as typed (no quoting) — **Ruling:** the form shows a live preview of the final command.
- Confirm before "Run in all tabs".

## Shared API (S1 defines exactly; S2–S4 code against it)
```swift
// CoreModels
extension Snippet { public var targetHostIDs: [UUID]? }          // new optional synced field ("Save targets")
public struct SnippetTemplate: Sendable, Equatable {             // AppCore/Snippets/SnippetTemplate.swift
    public struct Placeholder: Sendable, Equatable, Identifiable { public let name: String; public let defaultValue: String?; public var id: String { name } }
    public init(_ script: String)
    public let placeholders: [Placeholder]                          // distinct, in first-appearance order
    public var hasPlaceholders: Bool { get }
    public func filled(with values: [String: String]) -> String     // missing → default → ""
}
// AppCore/ViewModels/SnippetsViewModel.swift  (@MainActor @Observable)
public final class SnippetsViewModel {
    public init(vault: LocalVault)
    public var searchText: String
    public struct Section: Identifiable { public let package: String?; public let snippets: [Snippet]; public var id: String { package ?? "" } }
    public var sections: [Section] { get }                          // nil package first ("Snippets"), then packages A–Z; snippets A–Z; filtered by search
    public var packages: [String] { get }                           // distinct, sorted
    public func create(name: String, script: String, package: String?) -> Snippet
    public func update(_ id: UUID, name: String?, script: String?, package: String??)   // idempotent; trims name
    public func move(_ ids: [UUID], toPackage: String?)
    public func duplicate(_ id: UUID) -> Snippet?
    public func delete(_ id: UUID)
    public func saveTargets(_ id: UUID, hostIDs: [UUID]?)
    public func startupCandidates() -> [Snippet]                     // no placeholders
}
// AppCore SessionManager
public enum SnippetDelivery: Sendable { case paste, run }
public func deliver(_ text: String, as delivery: SnippetDelivery, toTab tabID: UUID) -> Bool      // false if tab not connected; newlines → "\r"; run appends "\r" unless text ends with a newline
public func deliverToAllTabs(_ text: String, as delivery: SnippetDelivery, inWindow windowID: UUID?) -> Int   // count delivered (connected tabs only)
public func connectableTabCount(inWindow windowID: UUID?) -> Int
public func runOnHosts(_ hostIDs: [UUID], text: String) throws -> [TerminalTab]   // opens a tab per host (main window), types text after .ready (after startup snippet and tmux attach — **Ruling:** before tmux attach? No: AFTER tmux attach so it runs inside the session the user sees)
```
