## Requirements (Cory's backlog, verbatim intent)
- **Connection screen.** While connecting (and when it fails), show a full screen in the tab instead of a blank terminal: host badge, name and "SSH <host>:<port>", plus a **Copy logs** button; a progress line from host to terminal that turns red on failure; a step-by-step connection log (address resolution, connecting to host/port, connection established, starting SSH session, closed with error e.g. "connection reset by peer"); buttons **Close**, **Edit host**, **Start over**.

## Shared API (P1 defines; P2 and P3 code against it exactly)
```swift
// SSHCore/TerminalSession.swift
public enum ConnectionStep: Sendable, Equatable {
    case resolving(host: String)                 // "Resolving <host>…"
    case connecting(address: String, port: Int)  // "Connecting to <address>:<port>…"
    case connected(address: String)              // "Connection established"
    case handshake                               // "Starting SSH session…"
    case authenticating(method: String)          // "Signing in with <password|key|1Password agent|keyboard>…"
    case authenticated                           // "Signed in"
    case openingShell                            // "Opening terminal…"
    case attachingTmux(session: String)          // "Attaching to tmux session <name>…" (sent by SessionManager, P3)
}
public enum SessionEvent { …; case progress(ConnectionStep) }   // emitted before .connected/.ready

// AppCore — on TerminalTab (@MainActor @Observable)
public struct ConnectionLogLine: Identifiable, Sendable, Equatable {
    public enum Status: Sendable, Equatable { case inProgress, done, failed }
    public let id: Int; public let step: ConnectionStep?; public let text: String
    public var status: Status; public let at: Date
}
public fileprivate(set) var connectionLog: [ConnectionLogLine]   // current attempt; reset when an attempt starts
public var connectionFailure: String? { get }                   // the failure text for the screen, nil if none
public var hasEverConnected: Bool { get }                       // this attempt reached .connected
public func connectionLogText() -> String                       // for Copy logs: header (host label, user@host:port, engine, date) + lines with timestamps
```

## P1 — core progress (branch v070-progress)
Owns: SSHCore `TerminalSession.swift` (ConnectionStep, SessionEvent.progress), `CitadelSession.swift`, `SystemSSH/*`, AppCore `SessionManager.swift` (event handling → connectionLog only), tests.
- **Citadel engine:** emit resolving (do the name lookup explicitly, async, with the existing timeout), connecting, connected (TCP up), handshake, authenticating(method), authenticated, openingShell; errors map to a failed last line with the existing SessionError message (add the low-level reason when known, e.g. "connection refused", "connection reset by peer", "no route to host", "host name not found").
- **System ssh engine:** run ssh with `-v -E <private temp file>` (0600, removed on close) so debug output never reaches the terminal; tail the file and map only these safe lines: "Connecting to X [ip] port N" → connecting, "Connection established" → connected, "Remote protocol version"/"Local version string" → handshake, "Authenticating to" / "Next authentication method: M" → authenticating(M), "Authentication succeeded" → authenticated, "Requesting … pty"/"Sending command"/"Entering interactive session" → openingShell. Everything else ignored. **Ruling:** if `-E` is unsupported, fall back to no progress (screen shows "Connecting…").
- SessionManager: append/update `connectionLog` lines from `.progress` (previous line → done, new → inProgress); on failure mark the last in-progress line failed and add a failed line with the message; reset at each new attempt (manual reconnect, auto-reconnect, Start over).
