### A — Theme pickers in Host Details and group menu (branch v061-pickers)
Owns: `App/Sources/UI/Hosts/HostDetailsPanel.swift`, `ThemePicker.swift`, `HostsView.swift`, `GroupCardView.swift`, new `App/Sources/UI/Themes/ThemeGallery.swift` (shared), `AppCore/ViewModels/HostDetailsViewModel.swift`/`HostsViewModel.swift` + tests.
- Move the host Theme row out of "Show more" to near the top of Host Details (directly after the address/port/credentials section — **Ruling**: right after the first card that holds Address/Label, before Group/Tags if that reads better; keep it visible in create and edit).
- The row is a button showing a small swatch (theme background + 4 ANSI bars, same drawing as Settings cards) + theme name, or "Default (<inherited name>)".
- Clicking opens a **popover gallery** (`ThemeGallery`): a scrollable grid of preview cards — each card is a mini terminal sample drawn in the theme's colors (background, foreground text like `user@host:~$ ls`, a few coloured words from ANSI red/green/yellow/blue/magenta/cyan, cursor block) and the name. First card "Default" shows the inherited theme with label "Default — <name>". Selected card has the accent ring. Clicking a card applies immediately (saves) and keeps the popover open so the user can compare; Esc/click outside closes.
- `ThemeGallery` is a reusable SwiftUI view: `ThemeGallery(catalog: TerminalThemeCatalog, selectedThemeID: String?, inheritedTheme: TerminalTheme?, showsDefault: Bool, columns: Int, onSelect: (String?) -> Void)` (nil = Default). Agent C uses it in the tab side panel — so A must commit `ThemeGallery.swift` FIRST (its own commit, early) and C copies nothing: C writes against this exact signature; the controller resolves at merge.
- Group card right-click → "Theme…" opens the same gallery (sheet or popover anchored to the card) for `HostGroup.defaultThemeID`; replace the old submenu. "Default" = no group theme.
- Fix parked minors: Host picker unknown-id handling stays; setTheme errors shown in the existing error alert (not `try?`); `inheritedThemeID` uses just this host (no decode of all hosts); swatch images cached per theme id.
