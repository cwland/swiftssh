## Requirements (from Cory's Termius screenshots + docs.termius.com/terminal/workspaces; backlog "Split view / workspaces")
- A **workspace** is one tab in the tab bar holding 2–16 terminal sessions ("panes"). Tab title = workspace name (default "Workspace"); a small grey dot on the tab when it differs from its saved template (or was never saved).
- **Split view:** all panes visible. Pane header: OS badge, host name, "ssh, <user>", status dot, and buttons Broadcast (tooltip "Broadcast input ⌘B"), Focus mode (tooltip "Focus mode ⌘⇧M"), Close (×); context menu: Move to New Tab (pop out), Rename (tab title only), Include/Exclude from broadcast, Change Theme…, Snippets…. Resizable dividers (drag; double-click resets to 50/50). Click focuses a pane (highlighted 2pt border); keyboard focus follows. Drag a pane by its header onto another pane's half to move it.
- **Drop zone:** while dragging a terminal tab (from the tab bar) or a host card over a terminal area, show a translucent overlay "Drag & Drop a terminal tab here to see it in a workspace view" and highlight the half (left/right/top/bottom by cursor position) where it lands. Dropping a tab moves that session into the pane; dropping a host opens a new connection in it. Dropping onto a plain terminal tab turns it into a workspace with both.
- **Focus mode:** one large terminal + a left list "Terminals • N" (OS badge, name, "ssh, <user>", status dot; selected row highlighted with × to close; drag rows to reorder); a button at the top of the list (tooltip "Split view ⌘⇧M") returns to Split. ⌘⇧M toggles. Switching never interrupts sessions.
- **Broadcast input** (⌘B or a pane's broadcast button): keystrokes typed in the focused pane are also sent to every *included* connected pane of the workspace. While on: focused pane solid border, other included panes dashed accent border, excluded panes no border + a "not broadcasting" badge. In Focus mode the selected terminal is the input target. Off again with ⌘B/the button. Paste/snippets Run with broadcast on → **Ruling:** also broadcast (Run in all panes = same path), Paste of multi-line still asks per the existing rule.
- **Status dots:** green = new output since the pane was last focused, yellow = waiting for input (host key / password prompt), red = failed or disconnected; none when focused and idle.
- **Saved workspaces (templates, this Mac only):** ⌘S (or clicking the grey dot) saves name, panes' host IDs (quick-connect panes saved by user@host:port), per-pane tab titles, layout tree with ratios, and view mode. Grey dot when unsaved changes; closing without saving leaves the template unchanged. Reopen from the tab bar "+" menu → "Saved Workspaces" submenu (open, rename, delete) and the Hosts screen toolbar "Workspaces" menu. Opening a template connects each pane.
- **Tab right-click on a plain terminal tab:** Split Right / Split Down → turns it into a workspace with a duplicate connection in the new pane. On a workspace tab: Rename…, Save Workspace (⌘S), Close Workspace (closes all its sessions).
- Closing a pane with 2 panes left converts the workspace back into a plain tab. Pop-out moves the pane to its own tab.
- Each pane keeps its own session: reconnect popup/banner, connection screen, keep-alive, per-host theme, side panels (theme/snippets) per pane, keyword highlighting.
- Multi-window: workspaces live in the window they were created in; "Duplicate in New Window" on a workspace → **Ruling:** not offered for workspaces this round.

## Shared API (W1 defines exactly; W2/W3 code against it)
```swift
// AppCore/Workspaces/PaneTree.swift
public enum SplitAxis: String, Codable, Sendable { case horizontal /* side by side */, vertical /* stacked */ }
public enum DropEdge: Sendable { case left, right, top, bottom }
public indirect enum PaneNode: Equatable, Sendable {
    case pane(UUID)                                   // a TerminalTab id
    case split(SplitAxis, ratio: Double, PaneNode, PaneNode)   // ratio = first's share, clamped 0.1…0.9
    public var paneIDs: [UUID] { get }                // reading order
    public func inserting(_ id: UUID, beside target: UUID, at edge: DropEdge) -> PaneNode
    public func removing(_ id: UUID) -> PaneNode?     // nil when empty; a split with one child collapses
    public func moving(_ id: UUID, beside target: UUID, at edge: DropEdge) -> PaneNode
    public func settingRatio(_ ratio: Double, atPath path: [Int]) -> PaneNode   // path: 0 = first, 1 = second
}
// AppCore/Workspaces/Workspace.swift
@MainActor @Observable public final class Workspace: Identifiable {
    public let id: UUID
    public var name: String
    public private(set) var root: PaneNode
    public enum ViewMode: String, Codable, Sendable { case split, focus }
    public var viewMode: ViewMode
    public var focusedPaneID: UUID
    public private(set) var isBroadcasting: Bool
    public private(set) var excludedFromBroadcast: Set<UUID>
    public var templateID: UUID?                      // the saved template it came from / was saved to
    public private(set) var hasUnsavedChanges: Bool
    public var paneIDs: [UUID] { get }
    public func status(of paneID: UUID) -> PaneStatus  // .none, .newOutput, .waitingForInput, .failed
}
public enum PaneStatus: Sendable { case none, newOutput, waitingForInput, failed }
// AppCore SessionManager (W1 adds; window-scoped like tabs)
public enum StripItem: Identifiable, Equatable { case tab(UUID), workspace(UUID); public var id: UUID }
public func strip(inWindow windowID: UUID?) -> [StripItem]       // tab bar order; tabs inside a workspace aren't listed
public func workspace(_ id: UUID) -> Workspace?
public func workspace(containing tabID: UUID) -> Workspace?
public func makeWorkspace(from tabIDs: [UUID], name: String?) -> Workspace?          // ≥2 tabs of the same window
public func openWorkspace(hostIDs: [UUID], name: String?) throws -> Workspace       // new connections, layout balanced grid-ish tree
public func addPane(tabID: UUID, to workspaceID: UUID, beside target: UUID, at edge: DropEdge)   // tab leaves the strip
public func addPane(hostID: UUID, to workspaceID: UUID, beside target: UUID, at edge: DropEdge) throws
public func splitTab(_ tabID: UUID, at edge: DropEdge) throws -> Workspace           // duplicate connection beside it
public func movePane(_ paneID: UUID, beside target: UUID, at edge: DropEdge, in workspaceID: UUID)
public func setRatio(_ ratio: Double, atPath path: [Int], in workspaceID: UUID)
public func popOutPane(_ paneID: UUID)                                               // back to its own tab; 1 left → workspace dissolves into a tab
public func closePane(_ paneID: UUID)                                                // ends the session; same dissolve rule
public func closeWorkspace(_ id: UUID)                                               // ends all its sessions
public func focusPane(_ paneID: UUID)                                                // clears its newOutput
public func setViewMode(_ mode: Workspace.ViewMode, for workspaceID: UUID)
public func toggleBroadcast(in workspaceID: UUID)
public func setPane(_ paneID: UUID, includedInBroadcast: Bool)
public func sendInput(fromTab tabID: UUID, _ bytes: [UInt8])     // the ONE entry point for typed input: broadcasts when the tab's workspace is broadcasting and the tab is the focused pane; else = send(tabID:)
public func noteOutput(tabID: UUID)                               // marks newOutput when not focused
// Saved templates (this Mac): AppCore/Workspaces/WorkspaceTemplateStore.swift — JSON file in Application Support (injectable URL for tests)
public struct WorkspaceTemplate: Codable, Identifiable, Equatable { public var id: UUID; public var name: String; public var layout: TemplateNode; public var viewMode: Workspace.ViewMode; public var savedAt: Date }
public indirect enum TemplateNode: Codable, Equatable { case pane(TemplatePane); case split(SplitAxis, ratio: Double, TemplateNode, TemplateNode) }
public struct TemplatePane: Codable, Equatable { public var hostID: UUID?; public var quickConnect: String?; public var title: String? }   // quickConnect "user@host:port"
@MainActor @Observable public final class WorkspaceTemplateStore { public init(fileURL: URL); public private(set) var templates: [WorkspaceTemplate]; public func save(_ workspace: Workspace, sessions: SessionManager) throws -> WorkspaceTemplate; public func rename(_ id: UUID, to name: String) throws; public func delete(_ id: UUID) throws }
public func openTemplate(_ template: WorkspaceTemplate) throws -> Workspace   // on SessionManager
```
